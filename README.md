# Vizel-Media-Player
Python music player without excessive memory consumption

Vizel was created to avoid playing music from heavy websites such as Spotify, YouTube, among others. 

***Memory consumption (Windows 11) -*** *45 MB* 

- Vizel uses PyWebview for a better viewing experience 
- You can configure the window however you want
